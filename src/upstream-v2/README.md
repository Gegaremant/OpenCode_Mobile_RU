# v2-клиент opencode-mobile

`v2-client.patch` — это правка, превращающая клиент `dzianisv/opencode-mobile`
в версию, которая говорит с **opencode 2.x** (маршруты под `/api/`, конверты
`{data, cursor}`, свой формат SSE), сохраняя совместимость с 1.x.

## Откуда она

Это **не мой код**. Это diff, снятый с ветки
[dzianisv/opencode-mobile#209](https://github.com/dzianisv/opencode-mobile/pull/209)
(коммит `bb395be`, автор — участник апстрима), который на момент 2026-10-01
ещё не смержен. Приложена поверх его родителя `646f9cb`:

```bash
git diff 646f9cb bb395be > src/upstream-v2/v2-client.patch
```

29 файлов, +3308 / −340. Внутри — `src/lib/sdk.ts` (v2-транспорт),
`src/lib/sdk-v1.ts` (старый транспорт), `src/lib/v2-shape.ts` (конвертация
v2 → внутренние формы), `src/lib/api-detect.ts` (определение поколения
сервера), `src/lib/message-text.ts` и изменения в сторах и экранах.

Положить его в этот репозиторий пришлось по практической причине: держать
сборку на форке оказалось ненадёжно. Форк `Gegaremant/opencode-mobile` был
создан, в него была запушена ветка, сборка с него прошла — а потом репозиторий
перестал отдаваться: анонимный `git ls-remote` на нём падал с кодом 128, а
GitHub API отвечал 404 и с токеном владельца, и без него. Никто из нас его не
удалял и не менял видимость. Поскольку рабочая копия этой правки лежит в
git-объектах локального клона, она сохранена здесь — в чужом репозитории
пропала бы вместе с ним.

## Как это применяется

В воркфлоу: клон апстрима → `git apply src/upstream-v2/v2-client.patch` →
наши собственные патчи из `src/patches/`. Если правка не применится, сборка
падает на этом шаге, а не собирает APK без v2-клиента.

Переменная `UPSTREAM_V2_OVERLAY` в `.github/workflows/sync-and-build.yml`
указывает на этот файл. **Когда #209 смердят в апстрим, значение надо
заменить на пустую строку** — тогда шаг `git apply` пропустится, и сборка
пойдёт прямо из апстрима.

## Как обновить

```bash
git fetch https://github.com/dzianisv/opencode-mobile.git refs/pull/209/head
git diff <родитель PR> FETCH_HEAD > src/upstream-v2/v2-client.patch
```

Если наши патчи перестанут накладываться на новое дерево — они для этого и
написаны: каждый падает с внятной ошибкой на своём маркере, а не собирает
молча неправильный APK.
